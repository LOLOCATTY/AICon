# AICon — AI connection for Autodesk Revit

Three things in one add-in:

1. **An AI bridge** — chat with Claude (or Gemini/DeepSeek/a local model, from a panel docked inside
   Revit) and it reads, analyzes, and edits the model you have open, in plain language. **77 tools**,
   every change is one undoable Revit transaction (Ctrl+Z).
2. **AR400** — one ribbon button turns "I need blockwork drawings for levels 4–9" into finished,
   numbered, annotated sheets. See [AR400](#ar400--shop-drawing-automation) below.
3. **Routines** — any capability the AI just did in chat can be saved as a real ribbon button that
   works offline, needs no AI key, and can be shared with a team by copying a folder. See
   [Routines](#routines--the-button-builder) below.

```
Claude Desktop  --MCP-->  AIConServer.exe  --localhost:55234-->  AICon add-in inside Revit
```

## Install — one click

1. Extract the AICon zip anywhere.
2. Double-click **`Setup.bat`**. It installs the Revit add-in for every Revit 2023–2027 on the
   machine, installs the AICon server, and connects Claude Desktop automatically
   (it will offer to close Claude Desktop if it's running).
3. Start Revit → click **Always Load** when asked about AICon (new **AICon** ribbon tab appears).
4. Open Claude Desktop, open a Revit project, and chat.

Requirements: Windows 10/11, Revit 2023–2027 (2023/2024 verified in daily use; 2025/2026/2027 build
and install cleanly and are supported, but have less field history — see `CHANGELOG.md`),
[Claude Desktop](https://claude.ai/download).
**No Python, no pyRevit, no Node, no .NET install** — fully self-contained.

## What you can ask

- "What's in my model? Any warnings?" / "Show me a screenshot of the active view"
- "Create a 6×4 m room with 3 m walls on Level 1, put a door in the south wall"
- "**Color the walls by fire rating** and give me the legend" (like pyRevit Color Splash)
- "Find all walls taller than 4 m, isolate them, then set their Comments to 'CHECK'"
- "Any clashes between structural columns and ducts?"
- "Make a sheet A-101 and place the Level 1 plan on it, then export it to PDF"
- "Give me a material takeoff of the floors in m³"
- Anything else — Claude can write and run C# **inside Revit** (`run_code`) for whatever
  has no dedicated tool: filters, worksets, MEP systems, dimensions, complex geometry...

Units: **millimeters** (areas m², volumes m³, angles degrees).

## AR400 — shop drawing automation

**AICon** tab → **Shop Drawings** panel → **AR400**. Pick one or more packages (Blockwork, Flooring,
General Arrangement, Ceiling, …), level(s), an optional scope box, and a title block. AR400 creates a
view + sheet for each package×level combination, places the view on it, applies that package's
configured view template, tags it, dimensions it, and adds a sheet schedule — sheet numbers/names can
come straight from an Excel drawing register. Everything happens in a single undoable transaction
(one Ctrl+Z), and re-running is safe — it never duplicates what's already there. Configure per-package
behavior in **AR400 Settings** on the same panel.

## Routines — the Button Builder

Any capability the AI just did in chat can be saved as a **real ribbon button**: works offline, needs
no AI key, and can be shared with a team by copying a folder to `%APPDATA%\AICon\routines`. Ask the AI
to save what it just did — it calls `save_routine` itself. Two kinds:

- **composed** — a saved sequence of ordinary AICon tool calls (no code, no compilation, always works).
- **script** — real C#, compiled in memory the first time it runs. Off by default; an owner turns it on
  in `%APPDATA%\AICon\routines.json` (`"allowCodeExecution": true`).

**AICon** tab → **Routines** panel → **Routines** browses and runs everything installed on this
machine (always current, no restart needed). Up to 8 routines also get their own dedicated ribbon
button, assigned at Revit startup — a routine saved mid-session runs fine from the browser immediately,
and gets its own button after the next restart.

## Why AICon instead of pyRevit MCP?

| | AICon | pyRevit-based MCP |
|---|---|---|
| Install | double-click Setup.bat | pyRevit + Python + uv + enable Routes manually |
| Dependencies | none (self-contained) | pyRevit, Python, uv |
| Sees the model | ✔ view screenshots to Claude | varies |
| Code escape hatch | C# (full native API speed) | IronPython |
| Revit startup impact | negligible (native C#) | pyRevit load time |
| Tools | 77 | ~48 |

## Ribbon

**AICon** tab → **AICon** (status), **Open Log** (`%APPDATA%\AICon\bridge.log`), **About**.

## Developing / rebuilding

```powershell
scripts\build-package.ps1     # builds everything, generates icons, zips dist\AICon-<version>.zip
```

Layout: `plugin\` (Revit add-in, C#, multi-targets net48/net8.0-windows/net10.0-windows for Revit
2023–2027), `server\` (MCP stdio server, C# net10, zero deps), `assets\make-icons.ps1` (logo
generator), `scripts\` (installer + packager).

## Troubleshooting

- **Claude can't reach Revit** — Revit not running / no project open / add-in not loaded
  (look for the AICon ribbon tab; check the log).
- **No "aicon" server in Claude Desktop** — fully quit Claude Desktop from the tray and reopen;
  re-run Setup.bat if needed (it closes Claude Desktop first for exactly this reason).
- **Calls time out** — Revit is showing a dialog or is in an edit mode; close it and retry.
- Bridge is `localhost:55234` — local machine only, nothing exposed to the network. Every call also
  needs a per-machine token AICon generates itself (`%APPDATA%\AICon\bridge.token`) — normal install
  and use never touches this file directly; it only matters if something else on the machine tries to
  talk to the bridge without going through AIConServer.exe or the console agent.
